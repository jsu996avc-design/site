Portal de Algorítmica y Programación

Unidad 1: Algoritmo y Programas

Concepto de Algoritmo: Un conjunto finito, preciso y ordenado de pasos lógicos que permiten resolver un problema o realizar una tarea específica.

Partes de un Algoritmo:
• Entrada: Datos iniciales necesarios.
• Proceso: Acciones y cálculos lógicos.
• Salida: El resultado esperado obtenido.

Formas de Representar:
• Lenguaje Natural: Narración simple del proceso.
• Pseudocódigo: Lenguaje intermedio cercano a la programación.
• Diagramas de Flujo: Representación gráfica simbólica.

Características: Debe ser Finito (tener fin), Definido (mismos pasos, mismo resultado), Preciso (orden riguroso) y Eficiente.

Unidad 2: Metodología para Análisis de Problemas

1. Análisis: Comprender el problema, identificar datos de entrada y resultados deseados.

2. Diseño: Crear la lógica del algoritmo (pseudocódigo o diagramas).

3. Codificación/Implementación: Traducir la lógica a un lenguaje de programación (C++, Python, etc.).

4. Ejecución: Puesta en marcha del programa en el computador.

5. Pruebas y Depuración: Detectar errores (bugs) y corregirlos para asegurar la calidad.

6. Mantenimiento: Actualizaciones y mejoras continuas del software.

7. Documentación: Registro escrito del funcionamiento interno y manual de usuario.

Unidad 3: Datos y Entidades

Datos vs Información: El dato es la mínima unidad semántica (ej. "20"). La información es el dato procesado con contexto (ej. "Edad: 20 años").

Tipos de Datos:
• Simples: Enteros (int), Reales (float/double), Caracteres (char), Lógicos (bool).
• Compuestos: Arreglos, estructuras, cadenas.

Variables y Constantes:
• Variable: Espacio de memoria cuyo valor cambia (ej. `int edad = 18;`).
• Constante: Valor inalterable (ej. `const float PI = 3.1415;`).

Operadores y Prioridad:
1. Paréntesis `()`
2. Potencia e Incrementos
3. Multiplicación, División y Módulo `* / %`
4. Suma y Resta `+ -`
5. Relacionales `< > <= >= == !=`

Ejercicio #1: Validación de Nota de Entrada

Enunciado: Desarrolle un programa en C++ que solicite al usuario la nota final de una asignatura. Utilizando una estructura repetitiva (ciclo do-while), valide que la nota ingresada esté estrictamente en el rango de 0 a 20. Si el usuario ingresa un valor fuera de este rango, el sistema debe mostrar un mensaje de error y volver a pedir la nota de forma indefinida hasta que el dato sea correcto. 

#include <iostream>
using namespace std;

int main() {
    float nota;

    // Ciclo do-while para obligar a introducir un dato válido
    do {
        cout << "Ingrese la nota final del estudiante (0 - 20): ";
        cin >> nota;

        if (nota < 0 || nota > 20) {
            cout << "Error: La nota ingresada no es valida. Intente de nuevo." << endl;
        }
    } while (nota < 0 || nota > 20);

    cout << "Nota registrada exitosamente: " << nota << endl;
    return 0;
}
Ejercicio #2: Sumatoría de Números Pares

Enunciado: Desarrolle un programa en C++ que solicite al usuario un número entero positivo N y calcule la suma de todos los números pares comprendidos entre 1 y N utilizando una estructura repetitiva (ciclo for). 

#include <iostream>
using namespace std;

int main() {
    int n, suma = 0;
    cout << "Ingrese un numero entero positivo: ";
    cin >> n;

    // Ciclo para evaluar y sumar los números pares
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 0) {
            suma += i; // Acumulador
        }
    }

    cout << "La suma de los numeros pares es: " << suma << endl;
    return 0;
}
Ejercicio #3: Cálculo de Factorial

Enunciado: Desarrolle un programa en C++ que lea un número entero positivo y calcule su factorial (N!) utilizando un bucle condicional repetitivo (ciclo while). El programa debe asegurar que el valor ingresado no sea negativo. 

#include <iostream>
using namespace std;

int main() {
    int n;
    long double factorial = 1; // Permite almacenar números grandes
    
    cout << "Ingrese un numero entero positivo: ";
    cin >> n;

    // Validación por si ingresan un número negativo
    if (n < 0) {
        cout << "El factorial de un numero negativo no existe." << endl;
    } else {
        int i = 1;
        while (i <= n) {
            factorial *= i; // Multiplicador acumulativo
            i++;
        }
        cout << "El factorial de " << n << " es: " << factorial << endl;
    }

    return 0;
}

        } else {
             cout << "El numero " << n << " NO es primo." << endl;
        }
    }

    return 0;
}
Ejercicio #5: Serie de Fibonacci

Enunciado: Diseñe un programa en C++ que genere y muestre en pantalla los primeros N términos de la Serie de Fibonacci, donde N es un número entero positivo proporcionado por el usuario. 

#include <iostream>
using namespace std;

int main() {
    int n, t1 = 0, t2 = 1, siguienteTermino = 0;

    cout << "Ingrese la cantidad de terminos a generar: ";
    cin >> n;

    cout << "Serie de Fibonacci: ";

    for (int i = 1; i <= n; i++) {
        if(i == 1) {
            cout << t1 << ", ";
            continue;
        }
        if(i == 2) {
            cout << t2 << ", ";
            continue;
        }
        
        siguienteTermino = t1 + t2;
        t1 = t2;
        t2 = siguienteTermino;
         
        cout << siguienteTermino;
        if (i < n) {
            cout << ", ";
        }
    }
    cout << endl;
    return 0;
}

#include <iostream>

    int numero, suma = 0, contador = 0;
    float promedio;

    cout << "Ingrese numeros positivos (metas uno negativo para terminar):" << endl;
    
    while (true) {
        cin >> numero;
        if (numero < 0) {
            break; // Rompe el ciclo si es negativo
        }
    
        suma += numero;
        contador++;
    }

    if (contador > 0) {
        promedio = (float)suma / contador;
        cout << "El promedio de los numeros es: " << promedio << endl;
    } else {
        cout << "No se ingresaron numeros positivos validos." << endl;
    }

    return 0;
}

    // Ciclo para evaluar el resto de los números

            mayor = numero;

Enunciado: Desarrolle un programa en C++ que solicite al usuario ingresar 6 números enteros para llenar un arreglo. #include <iostream>
using namespace std;

int main() {
    const int TAMANO = 6;
    int numeros[TAMANO];
    int aux;

    cout << "--- INGRESO DE ELEMENTOS ---" << endl;
    for (int i = 0; i < TAMANO; i++) {
        cout << "Ingrese el valor para la posicion [" << i << "]: ";
        cin >> numeros[i];
    }

    // Algoritmo para invertir el arreglo recorriendo hasta la mitad
    for (int i = 0; i < TAMANO / 2; i++) {
        // Intercambio de posiciones usando la variable auxiliar
        aux = numeros[i];
        numeros[i] = numeros[TAMANO - 1 - i];
        numeros[TAMANO - 1 - i] = aux;
    }

    cout << "\n--- VECTOR INVERTIDO ---" << endl;
    for (int i = 0; i < TAMANO; i++) {
        cout << "Posicion [" << i << "] = " << numeros[i] << endl;
    }

    return 0;
}

Ejercicio #7: Suma de la Diagonal Principal de una Matriz

Enunciado: Desarrolle un programa en C++ que declare e inicialice una matriz cuadrada de 4x4 con números enteros. El sistema debe recorrer la matriz para calcular de manera exclusiva la suma de los elementos que forman la diagonal principal (aquellas celdas donde el número de fila es igual al número de columna). Al final, muestre la matriz completa y el resultado de la sumatoria. 

#include <iostream>
using namespace std;

int main() {
    const int TAMANO = 4;
    // Declaración e inicialización directa de una matriz 4x4
    int matriz[TAMANO][TAMANO] = {
        {5,  8,  2,  1},
        {3,  9,  4,  7},
        {6,  2,  8,  3},
        {1,  5,  0,  4}
    };
    int sumaDiagonal = 0;

    cout << "--- MATRIZ COMPLETA 4x4 ---" << endl;
    for (int i = 0; i < TAMANO; i++) {
        cout << "\t[ ";
        for (int j = 0; j < TAMANO; j++) {
            cout << matriz[i][j];
            if (j < TAMANO - 1) cout << "   ";
            
            // Condición para identificar la diagonal principal (i == j)
            if (i == j) {
                sumaDiagonal += matriz[i][j]; // Acumulador selectivo
            }
        }
        cout << " ]" << endl;
    }

    // Mostrar el resultado del cálculo
    cout << "\nResultados del Analisis:" << endl;
    cout << "-> Los elementos evaluados son: ";
    for (int i = 0; i < TAMANO; i++) {
        cout << matriz[i][i];
        if (i < TAMANO - 1) cout << ", ";
    }
    cout << "\n-> La suma total de la diagonal principal es: " << sumaDiagonal << endl;

    return 0;
}

    } else if (montoVenta >= 1000 && montoVenta < 5000) {
        porcentajeBono = 0.03; // 3% Bono
    } else if (montoVenta >= 5000 && montoVenta < 10000) {
        porcentajeBono = 0.05; // 5% Bono
    } else if (montoVenta >= 10000 && montoVenta < 20000) {
        porcentajeBono = 0.08; // 8% Bono
    } else {
        porcentajeBono = 0.10; // 10% Bono (20000 o más)
    }

    // Cálculos financieros finales
    montoBono = montoVenta * porcentajeBono;
    totalPagar = montoVenta + montoBono;

    cout << "\n--- REPORTE DE BONIFICACIÓN ---" << endl;
    cout << "-> Monto de venta registrado: " << montoVenta << " Bs." << endl;
    cout << "-> Porcentaje de bono aplicado: " << (porcentajeBono * 100) << "%" << endl;
    cout << "-> Monto neto por concepto de bono: " << montoBono << " Bs." << endl;
    cout << "-> Total general a percibir: " << totalPagar << " Bs." << endl;

    return 0;
}
Ejercicio #9: Análisis Financiero y Distribución de Presupuesto

Enunciado: Un empresario debe decidir qué hacer si, actualmente su capital se encuentra en saldo negativo entonces, pedirá un préstamo bancario para que su nuevo saldo sea de 10000 Bs. Si su capital tiene actualmente un saldo positivo pedirá un préstamo bancario para tener un nuevo saldo de 20000 Bs. Pero si su capital tiene actualmente un saldo superior a los 20000 Bs no pedirá un préstamo. Posteriormente, repartirá su presupuesto de la siguiente manera: 5000 Bs para equipo de cómputo, 2000 Bs para mobiliario. Con el restante de su presupuesto repartirá la mitad para la compra de insumos y la otra para otorgar incentivos al personal. Muestre por pantalla cuánto le quedó para la compra de insumos y cuánto le quedó para otorgar incentivos al personal[cite: 146, 147, 148, 149, 150, 151, 152, 153]. 

#include <iostream>
using namespace std;

int main() {
    float capitalActual, presupuestoTotal;
    float prestamo = 0;
    float equipoComputo = 5000;
    float mobiliario = 2000;
    float restante, insumos, incentivos;

    cout << "Ingrese el capital actual de la empresa (Bs): ";
    cin >> capitalActual;

    // Evaluación del capital para determinar el préstamo y el presupuesto final
    if (capitalActual < 0) {
        presupuestoTotal = 10000;
        prestamo = presupuestoTotal - capitalActual;
    } else if (capitalActual <= 20000) {
        presupuestoTotal = 20000;
        prestamo = presupuestoTotal - capitalActual;
    } else {
        presupuestoTotal = capitalActual; // No solicita préstamo
    }

    cout << "\n--- BALANCE FINANCIERO ---" << endl;
    cout << "-> Prestamo solicitado: " << prestamo << " Bs." << endl;
    cout << "-> Presupuesto total: " << presupuestoTotal << " Bs." << endl;

    // Cálculo del presupuesto restante para las áreas variables
    restante = presupuestoTotal - (equipoComputo + mobiliario);

    if (restante < 0) {
        cout << "\nEl presupuesto no alcanza para cubrir los gastos fijos de computo y mobiliario." << endl;
    } else {
        insumos = restante / 2;
        incentivos = restante / 2;

        cout << "\n--- REPARTICIÓN DEL PRESUPUESTO ---" << endl;
        cout << "-> Equipo de computo: " << equipoComputo << " Bs." << endl;
        cout << "-> Mobiliario: " << mobiliario << " Bs." << endl;
        cout << "-> Compra de insumos: " << insumos << " Bs." << endl;
        cout << "-> Incentivos al personal: " << incentivos << " Bs." << endl;
    }

    return 0;
}
